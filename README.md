# Видеообои: «один раз после разблокировки»

Android-приложение с живыми обоями из вашего видео. Настройки применяются сразу,
переустанавливать обои не нужно.

**Когда запускать** (можно несколько): при разблокировке, при включении экрана (прямо на
экране блокировки), при возврате на рабочий стол. «Только один раз» — после первого
проигрывания видео больше не запускается, пока не нажать «Проиграть сейчас».

**Как проигрывать:** сколько раз подряд (1–20 или ∞) и на каком кадре остановиться —
последнем или первом.

**При блокировке экрана:** оставить как есть, вернуть к началу мгновенно или плавно
реверсом: на экране блокировки видео идёт назад, после разблокировки — вперёд с того же
кадра. Вперёд всегда играет оригинал без перекодирования; для реверса один раз готовится
копия видео задом наперёд.

**Эффекты:** масштаб при разблокировке (приблизить или отдалить, с силой) и параллакс от гироскопа (сила ползунком).

**Дополнительно:** звук, «Проиграть сейчас», журнал событий для диагностики.

По умолчанию: видео проигрывается один раз при каждой разблокировке, замирает на последнем
кадре и после блокировки возвращается к началу.

## Как получить APK

Прямая ссылка на последнюю сборку:
https://github.com/Deaddeaddeaddead/Dead/releases/latest/download/VideoWallpaper.apk

Каждый push собирается в GitHub Actions и обновляет релиз `latest`. Или локально: `./gradlew assembleDebug`
(нужен Android SDK) → `app/build/outputs/apk/debug/app-debug.apk`.

## Как пользоваться

1. Откройте «Видеообои», нажмите «Выбрать видео» (файл копируется внутрь приложения).
2. Настройте поведение.
3. «Установить как обои» → выберите «Главный экран и экран блокировки» (или только главный).
4. Заблокируйте и разблокируйте телефон — видео запустится.

## Ограничения

- Сразу после установки обоев видео ждёт первой разблокировки (это и есть «только после разблокировки»).
- Живые обои на экране блокировки поддерживают не все прошивки (например, Samsung One UI часто ставит
  на экран блокировки свои обои). На главном экране работает везде.
- Видео масштабируется с обрезкой по краям под экран.
- Реверс требует перекодирования видео на телефоне; если кодировщик телефона не справится,
  приложение покажет причину и будет возвращать к началу мгновенно.
