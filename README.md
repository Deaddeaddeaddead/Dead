# Видеообои: «один раз после разблокировки»

Android-приложение с живыми обоями из вашего видео. Настраивается:

| Настройка | Что делает |
|---|---|
| Зациклить | Видео крутится бесконечно |
| Количество проигрываний | Сколько раз подряд проиграть (1–100), если не зациклено |
| После окончания оставить последний кадр | Видео замирает на последнем кадре (без возврата). Выключено — возврат к первому кадру |
| Запускать только после разблокировки | На экране блокировки видео стоит; стартует только после разблокировки |
| Проигрывать повторно | Выключено — видео проиграется один раз и больше не запустится |
| ↳ Заново после каждой блокировки экрана | Каждый раз после блокировки серия готовится заново и (с «только после разблокировки») стартует при разблокировке |
| ↳ Заново при каждом возврате на рабочий стол | Повтор, когда обои снова становятся видны |
| Звук | По умолчанию выключен |
| Возвращать к началу (после блокировки) | После блокировки видео возвращается к первому кадру |
| ↳ Возврат реверсом | Видео плавно проигрывается назад на экране блокировки (разовая подготовка видео, без звука) |
| Приближение при открытии приложений | Обои приближаются при открытом приложении и плавно отдаляются при возврате |
| Проиграть заново | Сбрасывает «уже проиграно» |

**Настройки по умолчанию** — ровно сценарий «проиграть один раз без возврата, только после разблокировки».
Если нужно «один раз при *каждой* разблокировке» — включите «Проигрывать повторно» и «Заново после каждой блокировки экрана».

## Как получить APK

Прямая ссылка на последнюю сборку:
https://github.com/Deaddeaddeaddead/Dead/releases/latest/download/VideoWallpaper.apk

Каждый push собирается в GitHub Actions и обновляет релиз `latest`. Или локально: `./gradlew assembleDebug`
(нужен Android SDK) → `app/build/outputs/apk/debug/app-debug.apk`.

## Как пользоваться

1. Откройте «Видеообои», нажмите «Выбрать видео» (файл копируется внутрь приложения).
2. Настройте поведение.
3. «Установить как обои» → выберите «Главный экран и экран блокировки» (или только главный).
4. Заблокируйте и разблокируйте телефон — видео запустится.

## Ограничения

- Сразу после установки обоев видео ждёт первой разблокировки (это и есть «только после разблокировки»).
- Живые обои на экране блокировки поддерживают не все прошивки (например, Samsung One UI часто ставит
  на экран блокировки свои обои). На главном экране работает везде.
- Видео масштабируется с обрезкой по краям под экран.
- Реверс требует перекодирования видео на телефоне; если кодировщик телефона не справится,
  приложение покажет причину и будет возвращать к началу мгновенно.
- Плавное приближение синхронно с анимацией открытия приложения работает там, где лаунчер
  сообщает обоям «зум» (Pixel и близкие к чистому Android). На остальных прошивках обои
  плавно отдаляются при возврате на рабочий стол.
